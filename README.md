# Bomse Workshop — сайт-шахта

Одностраничный сайт для Bomse Workshop (тату, парикмахерская, мастерская в старой лифтовой шахте Нижполиграфа, Нижний Новгород, Варварская, 32). При прокрутке камера поднимается по 3D-шахте: общий план здания → четыре этажа → крыша с формой записи.

## Запуск

Сборка не нужна: откройте `index.html` в браузере, работает и с диска. Three.js лежит локально в `vendor/`, из интернета грузятся только шрифты Google Fonts.

## Структура

```
bomse-workshop/
├── index.html        # Разметка и все тексты этажей
├── css/style.css     # Стили, мобильная версия (до 860px)
├── js/
│   ├── data.js       # Контакты, услуги и цены, работы, ключ формы — правится без кода
│   ├── scene.js      # 3D-сцена: шахта, интерьеры, камера (всё рисуется кодом)
│   └── main.js       # Скролл → положение лифта, лифтовая панель, форма
└── vendor/three.min.js   # Three.js 0.160.0 одним файлом
```

## Как менять контент

Всё, что нужно уточнять у ребят, лежит в [js/data.js](js/data.js):

- **Контакты** — `contacts`: телефон, Telegram, часы работы, «как найти». Пустое поле просто не показывается.
- **Услуги и цены** — `services.barber / tattoo / workshop`. Пока `price` пустой, на сайте стоит «по запросу».
- **Работы** — положите фото в `assets/works/` и впишите путь в `works[n].image`. Без фото на месте работы рисуется пронумерованный флеш-лист.
- **Форма** — впишите ключ Web3Forms в `web3formsKey`, и заявки пойдут на почту. Без ключа форма копирует текст заявки и ведёт в директ Instagram.

Тексты этажей (заголовки, абзацы, шаги) правятся прямо в [index.html](index.html).

## Как менять этажи

Этаж — это секция в `index.html` плюс комната в `scene.js`, связаны они порядком.

- **Секция**: `<section class="floor" id="floor-N" data-stop="N">`. `data-stop` — номер остановки лифта (0 — первый экран, 1–4 — этажи, 5 — крыша).
- **Кнопка лифта**: `<a href="#floor-N" data-stop="N">` в блоке `.lift__buttons`.
- **Комната**: блоки `// ----- N этаж -----` в [js/scene.js](js/scene.js). Мебель собирается из `box()`, `cyl()`, `plane()`; координаты в метрах от центра пола комнаты.
- **Подпись на перекрытии**: массив `LABELS` в начале `scene.js`.

Чтобы поменять этажи местами, переставьте секции в HTML, блоки комнат в `scene.js` (номер в `floorGroup(...)`) и подписи в `LABELS`.

## Что не подтверждено и требует сверки с заказчиком

- Назначение этажей (1 — вход, 2 — парикмахерская, 3 — тату, 4 — мастерская) — предположение.
- Список услуг, формулировки про эскизы, расходники и памятку — черновик.
- Цены, телефон, часы работы, «как найти вход» — пусто.
- Связь мастерской с граффити-командой Bomse взята из открытых источников (галереи, афиши), у самих ребят не уточнялась.
- Фото работ: Instagram при сборке был недоступен, в галерее стоят заглушки.
